# Empório Vizinho — Landing Page

Estrutura do projeto:

    index.html        -> estrutura da página (HTML semântico + SEO)
    css/style.css     -> estilos (design tokens, layout, animações, responsivo)
    js/script.js      -> comportamento (WhatsApp, menu, scroll reveal, contador)
    assets/images/    -> pasta para fotos próprias da loja (substituir as do Unsplash)

Antes de publicar, edite:

1. js/script.js -> WA_CONFIG.numero (WhatsApp) e WA_CONFIG.horaFechamento
2. index.html   -> endereço, horários, link do Google Maps e redes sociais no rodapé
3. index.html   -> trocar as fotos do Unsplash pelas fotos reais (colocar em assets/images/)
4. index.html   -> nomes/depoimentos e história em "Sobre" (são fictícios)

Para testar: abra o index.html no navegador (duplo clique).
